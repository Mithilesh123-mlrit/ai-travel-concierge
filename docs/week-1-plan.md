# AI Travel Concierge – Track A

## Project Idea

The AI Travel Concierge is an AI-powered travel assistant that will
help users with travel-related queries through a web-based interface.

The project will use an LLM with LangChain and RAG as the initial
foundation. The application will gradually be extended with travel
APIs, tool calling, itinerary generation, and persistent storage
according to the Track A project plan.

## Week 1 Objective

The main objective for Week 1 is to build the initial foundation of
the AI Travel Concierge.

The focus will be on:

- Setting up the Python development environment
- Integrating LangChain with an LLM
- Implementing document upload
- Building a basic RAG pipeline
- Creating a Streamlit interface
- Testing question answering using uploaded travel documents

## Plan of Action

### Day 1 – Project Setup

- Set up the Python development environment
- Create the required project structure
- Install the required libraries
- Configure the LLM environment
- Prepare GitHub repository and project documentation

### Day 2 – LLM Integration

- Connect the selected LLM with the application

### Day 3 – Document Upload

- Implement document upload functionality

### Day 4 – RAG Implementation

- Split documents into suitable chunks
- Generate embeddings

- Connect the retrieved information with the LLM
- Test question answering using uploaded documents

### Day 5 – Streamlit Integration

- Integrate the RAG workflow into the Streamlit application
- Allow users to upload travel documents
- Allow users to ask questions about the uploaded documents
- Display the generated responses clearly

### Day 6 – Testing and Improvements

- Test the application with different travel-related questions
- Check whether responses are based on the uploaded documents
- Test basic error cases
- Fix issues found during testing
- Improve the application where required

### Day 7 – Final Review and Documentation

- Perform final testing of the Week 1 implementation
- Clean up the project files and code
- Update the README with the current progress
- Add screenshots if required
- Push the completed Week 1 work to GitHub

## Expected Outcome

By the end of Week 1, the goal is to have a basic working
RAG-based AI Travel Assistant with a Streamlit interface,
document upload, and question-answering functionality.

This will provide the foundation for the next stages of the
project, including travel API integration and tool calling.
